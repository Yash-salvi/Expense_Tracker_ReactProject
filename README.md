# Expense_Tracker_React

A React-based Expense Tracker application to record, manage, and monitor daily income and expenses efficiently.

## Features
- Add income and expense transactions
- Delete transactions
- Track current balance dynamically
- View transaction history
- Built using React components, hooks, and state management

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## Project Description
This project helps users manage their daily finances by allowing them to add and remove transactions while automatically updating the total balance. It is designed to provide a simple and user-friendly interface for expense tracking.
